# 使用界線

本 repo 是**工程技術案例**：示範時間窗內多步驟表單的狀態機、回讀驗收、防重送、失敗停手。它只附**模擬平台**，刻意不附任何真實平台的程式。

## 明確的界線

1. **簽到／簽退紀錄不能替代實際出席。** 不要用它在你沒有實際參與的課程上產生出席紀錄。
2. **資格、學分、證照、研究倫理訓練等相關測驗，應依所屬機構規則由本人完成。** 自動作答模組在本 repo 的定位，是針對模擬平台的「文件問答」示範。
3. **接入任何真實系統前，須取得該系統與所屬機構的適用授權**，並遵守其使用條款；許多平台禁止自動化操作。
4. 不要替別人操作其帳號。
5. 帳密與 API 金鑰只放在 `secrets.env` 或環境變數，不要進版本控制。
6. 備援代理人具有執行指令的能力，技術上可以讀到本機檔案；若你不接受這個風險，就不要設定 `[fallback]`，失敗時只通知你。

以上是建議的使用界線，不是對任何機構規則的法律判定；各機構規定不同，請以你所屬機構為準。

作者與貢獻者不為違反機構規定或平台條款的使用負責。
