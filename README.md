# gcp-course-autopilot

> 一個**技術案例**：在內建的**模擬線上課程平台**上，實作「有時間窗、多步驟、不能重做」的網頁表單工作流程（報名 → 簽到 → 簽退 → 問卷 → 選擇題測驗），重點是**失敗時如何停手、如何避免重複送出、如何驗收**。
> English summary: [README.en.md](README.en.md)

---

## 你可以從這裡學到什麼

1. **狀態機＋回讀驗收**：每一步送出後，回頭讀「學員卡」上的狀態；只有出現合法時間戳（或 0–100 的分數）才算完成，看不懂的文字一律視為未知狀態並停手。
2. **不確定就不重送**：送出前把「待確認」寫進磁碟；送出後只要網路或轉址出錯，就當作「結果不明」，不重送、通知人。平台有明確回應但狀態沒更新時，才允許有限次重試。
3. **期限放在送出前一刻**：每次 POST 前重讀時鐘；AI 呼叫與代理人都帶絕對期限。
4. **AI 放在最小範圍**：只在「需要理解內容」（選擇題作答）與「頁面改版時的備援」兩處使用，輸出都要經程式驗證。

## 快速開始（Python 3.11+，macOS／Linux）

```bash
pip install -r requirements.txt
python demo.py            # 在模擬平台上快轉一天：報名 → 預檢 → 簽到 → 簽退 → 問卷 → 測驗
python demo.py --wrong    # 故意答錯：第 1 次 0 分 → 重答一次 → 仍不及格 → 停手並通知
python -m unittest discover -s tests -t .   # 95 項測試，全部只連本機模擬平台
```

備援瀏覽器助手另需 `pip install playwright && playwright install chromium`（不用備援可不裝）。

## AI 可以替換，也可以不用

| 用途 | 設定 | 選項 |
|---|---|---|
| 選擇題作答 | `[[answer.providers]]`，依序嘗試 | `static`（演示，不用 AI）、Gemini／OpenAI／Anthropic／xAI 的 HTTP API、任何命令列代理人 |
| 頁面改版時的備援 | `[fallback] command = [...]`（可不設） | 任何能在非互動模式執行的代理人 CLI |

程式**不預設任何模型**；使用 HTTP API 時必須自己填 `model`。建議優先使用 HTTP API：它們是純模型呼叫、沒有工具，頁面上的外來文字沒有機會指揮它存取你的電腦。命令列代理人通常能執行指令；我們實測過某個代理人 CLI 的 `--sandbox` 在「自動同意」設定下仍能讀檔、執行指令，所以它只放在最後一線，這個風險也寫在文件裡。

## 各項設計的實際保證範圍

| 主題 | 程式實際做到的 | 做不到／不保證的 |
|---|---|---|
| 完成判定 | 只有合法時間戳或 0–100 分數才算完成；缺列、重複列、未知文字都停手 | 平台若把錯誤狀態寫成合法時間戳，程式無從分辨 |
| 重複送出 | 送出前寫「待確認」；結果不明（斷線、轉址失敗）不重送；已及格不重考 | 平台明確回應 200 但狀態未更新時，會在時間窗內有限次重試 |
| 期限 | 每次 POST 前檢查；AI／代理人呼叫以剩餘時間為上限 | 平台端時鐘與本機不同步時的誤差 |
| 表單驗證 | 出席、問卷、測驗表單逐欄點名核對，多或少一個欄位就停手 | 報名模組是針對模擬平台的參考實作，選擇器寫在程式裡 |
| 備援代理人 | 被要求只使用 `browser_helper.py`；該助手代填帳密、以網路層攔截限制為單一課程、單一步驟、每次執行一次送出，已完成的步驟拒絕動作 | 這是**行為護欄，不是隔離**：有執行權限的代理人技術上仍可讀本機檔案或自行發請求 |
| 機密 | 帳密與金鑰只從 `secrets.env`／環境變數讀取；日誌、狀態檔、通知會遮蔽（含 JSON 跳脫形式） | 交給備援代理人的機器上，代理人自身的行為 |
| 附件外送 | 只下載平台本身或 `material_hosts` 允許主機上的附件，轉址只跟隨到允許主機；抽出的文字會送給你設定的作答供應商 | 允許主機上的內容本身是否適合送給外部模型，需自行判斷 |
| 演練 `--dry-run` | 不寫任何本機檔案、不送任何會改變狀態的表單、不呼叫 AI、不通知 | 仍會**登入一次**以讀取狀態 |
| 通知 | 出席程式的通知先進 outbox，送不出去定期重送 | 報名程式的通知直接送出，沒有 outbox |

## 檔案

```
autopilot/site.py            平台客戶端（嚴格表單驗證、無自動轉址、送出前期限檢查）
autopilot/runner.py          每分鐘一次的狀態機（時間窗、待確認、收據、備援、通知、狀態檔）
autopilot/answering.py       選擇題作答供應商（static / Gemini / OpenAI / Anthropic / xAI / CLI）
autopilot/fallback.py        備援代理人交接（指令範本由設定決定）
autopilot/browser_helper.py  備援專用瀏覽器助手（Playwright；代填帳密＋網路層限制）
autopilot/register.py        報名（模擬平台的參考實作：一次最多送一門、送出前記意圖）
mock_site/server.py          模擬課程平台（無外部依賴）
demo.py                      快轉一天的演示
config.example.toml          設定範例（沒有預設模型）
docs/                        設計、踩坑、使用界線
```
